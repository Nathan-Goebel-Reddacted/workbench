# Vision

## Objectif

Un espace personnel en deux parties :

- **Public** — portfolio visible par tous : qui je suis, mes projets, mon CV
- **Privé** — atelier de planification : éditer le portfolio, documenter, théoriser, réfléchir

## Philosophie

L'espace privé n'est pas un simple CMS. C'est un atelier de création et de réflexion :
gérer ses projets actifs, capturer ses idées, planifier, documenter — avec l'aide de l'IA.

## Public cible

- **Public** : recruteurs, collaborateurs, curieux
- **Privé** : moi seul

## Principes directeurs

- DDD : le domaine prime sur la technique
- Modularité : les pages projet publiques sont construites par grille, section par section
- IA en soutien : pré-remplissage vocal, agents connectés — jamais imposés
- Documentation légère mais structurée
