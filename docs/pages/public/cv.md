# Page : CV (public)

## Objectif

Permettre à un visiteur de consulter et télécharger un CV.

## Header (global)

Présent sur toutes les pages publiques :
- Nom / logo du site à gauche
- Navigation à droite : Home, CV

## Composants

### 1. Sélecteur de CV

- Liste des CVs disponibles (ex: "Dev Full Stack FR", "Dev Full Stack EN")
- Sélection → met à jour le visualisateur
- Le CV affiché par défaut est celui marqué "actif" dans le CV Manager

### 2. Visualisateur PDF

- Affichage inline du PDF sélectionné

### 3. Bouton de téléchargement

- Télécharge le PDF affiché

## Notes

- Aucun compte requis pour consulter ou télécharger
- Les CVs sont uploadés et gérés depuis l'espace privé (Editor → CV Manager) uniquement
