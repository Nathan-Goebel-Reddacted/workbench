# Page : Editor (privé)

## Objectif

Éditer le contenu de la partie publique : profil de la home et CVs.

## Sections

### 1. Éditeur de profil (Home)

Champs éditables :
- Nom complet
- Titre / poste (ex: "Développeur Full Stack")
- Bio courte (texte libre, quelques lignes)
- Liens de contact :
  - GitHub
  - LinkedIn
  - npm
  - Email
  - Site personnel (optionnel)

Gestion de l'ordre des projets publics :
- Liste des projets avec `public = true` (nom + logo)
- Réordonner par drag & drop — définit l'ordre d'affichage sur la home
- La visibilité (`public` / `privé`) se gère depuis la fiche projet dans le ProjectCatalog

### 2. CV Manager

- Uploader un nouveau PDF (avec nom libre, ex: "Dev Full Stack FR")
- Renommer un CV existant
- Définir le CV actif (affiché par défaut sur la page CV publique)
- Supprimer un CV

## Notes

- Pas d'édition des ProjectPages ici — elles sont gérées depuis le Project Catalog
- Aucune photo de profil
