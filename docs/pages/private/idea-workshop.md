# Page : Idea Workshop (privé)

## Objectif

Espace de réflexion libre pour théoriser des projets non démarrés
et tenir un journal de bord pour les projets actifs.

## Sections

### 1. Boîte à idées

- Cartes idées : titre, tags, date de création
- Filtres : tags
- Bouton "Nouvelle idée"

### 2. Fiche idée

Champs :
- Titre
- Description longue (texte libre)
- Tags (multi-sélection partagés avec ProjectCatalog)

Actions :
- Accéder aux mindmaps liées
- Accéder au DevLog de l'idée
- **"Convertir en projet"** — crée un Project dans ProjectCatalog avec le titre, la description et les tags pré-remplis. L'Idea reste et est liée au Project créé.

### 3. Mindmaps

- Liste des mindmaps liées à l'Idea (ou à un Project depuis le ProjectCatalog)
- Créer une nouvelle mindmap → ouvre l'éditeur MindMeister embarqué (Embed API)
- Ouvrir une mindmap existante → éditeur MindMeister embarqué
- Une mindmap est liée à une Idea OU à un Project, pas aux deux

### 4. DevLog

- Journal chronologique par Idea ou Project
- Entrées horodatées, texte libre
- Ajouter une entrée manuellement
- Ajouter une entrée par saisie vocale (via AIAssistant STT) :
  1. Enregistrement vocal → transcription affichée en brouillon
  2. Édition possible avant validation
  3. Validation → entrée ajoutée au DevLog
